{%- comment -%} pre block with selectable strong ranges inline. Reproduces live's fritzbox config snippets where WordPress emits pre containing literal strong tags. Kramdown cannot emit strong inside a fenced code block (the asterisk markup appears literal). This include is the no-raw-HTML alternative -- pass the already-bolded text as a single string via a captured variable; literal strong tags in the captured value pass through. Params: style optional inline style for the pre content pre-bolded HTML string (literal strong tags are emitted verbatim) inline if truthy, emit the pre WITHOUT the nomarkdown wrapper so it can sit inside an li or other block-level context where the nomarkdown block marker would otherwise break the surrounding structure. Relies on parse_block_html: true. When NOT inline, wrapped in nomarkdown so Kramdown does not parse-block-html the literal pre / and wrap it in a p. {%- endcomment -%} {%- if include.inline -%}{{ include.content }}{%- else -%} {::nomarkdown} {{ include.content }} {:/nomarkdown} {%- endif -%}

{%- comment -%} Bare pre block (no Rouge wrappers, no inner code element), optionally wrapped in a blockquote. Reproduces live's WP-rendered code-in-blockquote markup where WordPress emits bare pre style="..." tags inside a blockquote. Kramdown's fenced/indented code emits .language-plaintext.highlighter-rouge wrappers with an inner code tag, which renders at a slightly different font weight and lacks the inline padding-left, so it cannot byte-match live's bare pre. This include is the no-raw-HTML alternative. Usage: capture each content block into a variable, then call this include with content1=.., content2=.., (up to content5), blockquote=true to wrap all the pre blocks in a blockquote, and style="..." to apply an inline style to every pre (e.g. "padding-left: 30px;"). Params: blockquote truthy -> wrap output in a blockquote style inline style applied to every pre content single block (use this OR content1..content5) content1..content5 up to 5 blocks, each emitted as its own pre The {::nomarkdown} ... {:/nomarkdown} markers MUST be on their own lines so Kramdown recognizes them as block-level extension markers. Otherwise Kramdown wraps them in p tags and emits literal text. {%- endcomment -%} {%- if include.inline -%}{{ include.content }}{%- else -%} {::nomarkdown} {% if include.blockquote %}
